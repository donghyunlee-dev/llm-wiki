# Search Flow Contract Freeze Spec

## Scope
- Freeze the current search and guide-page behavior into a single canonical contract.
- Remove ambiguity around answer prefixes, section ordering, and guide-page linkage.
- Make future implementation changes follow the contract instead of reshaping it ad hoc.

## Acceptance Criteria
- A canonical PRD contract exists for search and guide-page behavior.
- The contract defines the visible answer format, section order, and guide-page linkage rules.
- The contract defines guide-page rendering rules for code, callouts, summaries, and active TOC behavior.
- The contract is referenced from the development plan and implementation status.
- The work is doc-first and does not require code changes to be considered complete.

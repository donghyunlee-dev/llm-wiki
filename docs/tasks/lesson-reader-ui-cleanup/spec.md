# lesson-reader-ui-cleanup Spec

## Problem Statement
참고 사이트(https://sfood-ai-education.leedh84.chatgpt.site/) 대비 비교 분석 후 사용자가 지적한 레슨 리더 UI 3건을 수정한다.
1. 상단에 "이 레슨 X/Y"와 "전체 X/Y" 두 개의 카운터가 나란히 표시되어 중복/혼란스럽다.
2. "이전" 버튼이 배경과 같은 색이라 버튼처럼 보이지 않는다.
3. "학습 흐름" 드로어에서 레슨 제목과 씬 제목이 위아래로 중복 표시되고, 예상 소요 시간("약 N분")이 불필요하게 표시된다.

## Business Context
레슨=씬이 1:1인 현재 콘텐츠 구조에서 위 UI들이 같은 정보를 두 번 보여주거나 클릭 가능성을 인지하기 어렵게 만들어 사용성을 해친다.

## Scope
- `LessonReaderPage.tsx` 상단 카운터를 단일 카운터로 정리 (`globalPosition` 있으면 "전체 X/Y"만, 없으면 "이 레슨 X/Y"만).
- `.lesson-reader-nav-button`(이전 버튼) 배경/테두리 대비 개선.
- `LessonOutlineDrawer.tsx`에서 레슨 제목 줄 + 씬 목록 줄의 중복 제거, "약 N분" 표시 제거, 챕터 헤더 아래 타이틀 전용 리스트로 단순화.

## Out Of Scope
- 레슨/씬 데이터 모델, 카운터 계산 로직(`getGlobalScenePosition`) 자체 변경.
- 챕터 그룹핑 자체의 제거(챕터 헤더는 유지).
- 다른 화면(홈, `/lesson` 목록 등)의 카드 요약 중복 버그(별도 태스크).

## User Or Operator Scenarios
- 사용자가 레슨을 읽다가 상단 진행률을 확인할 때 하나의 숫자만 본다.
- 사용자가 첫 씬이 아닌 곳에서 "이전" 버튼을 인지하고 클릭할 수 있다.
- 사용자가 "학습 흐름"을 열면 23개 레슨 제목이 시간 표시 없이 한 줄씩 나열된 리스트로 보인다.

## Acceptance Criteria
- AC1: 레슨 리더 상단에 카운터가 하나만 표시된다.
- AC2: "이전" 버튼이 라이트/다크 테마 모두에서 배경과 구분되어 보인다.
- AC3: 학습 흐름 드로어에서 각 레슨이 제목 한 줄(및 챕터 헤더)로만 표시되고 "약 N분" 텍스트가 없다.
- AC4: 기존 씬 이동/포커스/키보드 네비게이션 동작에 회귀가 없다.

## Edge Cases
- 레슨에 씬이 2개 이상인 경우(현재 실 데이터엔 없음): 레슨 단위 제목 줄이 사라지므로 각 씬이 개별 리스트 항목으로만 보인다 — 사용자 확인 완료(허용).
- `globalPosition`이 없는 경우(코스 순서 계산 실패): "이 레슨 X/Y"로 폴백.

## Assumptions
- 현재 실 콘텐츠는 23개 레슨 모두 레슨당 씬 1개 구조를 유지한다.

## Clarifications
- Q: 다건 씬 레슨이 생기면 레슨 제목 줄 없이 씬들이 나열되는데 괜찮은가?
- A: 사용자 승인(진행 지시로 확인).

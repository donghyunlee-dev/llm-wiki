# lesson-reader-side-rail-and-dock-height-fix Spec

## Problem Statement
1. 콘텐츠가 가운데(`max-w-5xl`)에만 표시되고 넓은 화면에서 좌우 여백이 그대로 낭비됨 — "다음: ..." 안내를 그 여백(우측 사이드)으로 빼자는 사용자 제안.
2. 작은 노트북 모니터에서 "교육 설명" 패널 높이가 상대적으로 너무 커서 씬 콘텐츠(카드 그리드 등)를 가림.
3. (버그 리포트 계기로 조사 중 발견) "교육 설명 숨기기" 토글 자체는 정상 동작하지만, `ResizeObserver` 기반 dock 높이 측정이 로딩 완료 후 단 한 번도 실행되지 않아 늘 폴백 값(8rem)만 쓰이고 있었음 — 짧은 씬+작은 모니터 조합에서 스크롤이 전혀 안 생겨 dock에 가려진 콘텐츠를 영원히 볼 수 없는 상태였음.

## Scope
- `xl`(1280px) 이상 화면에서 "다음: ..." 안내를 우측 사이드 레일로 이동(그 아래에서는 기존 하단 dock 안 배치 유지).
- "교육 설명" 패널 높이를 `clamp(96px, 22vh, 260px)`로 조정 — vh 비율은 유지하되 낮은 화면에서 더 적극적으로 줄어들게 함.
- `ResizeObserver` 이펙트가 로딩 완료 후에도 실제로 붙도록 수정.
- (부수적으로 발견) `.lesson-reader-shell`의 `min-height`가 짧은 씬에서 스크롤 자체를 없애버리는 문제 → 제거.

## Out Of Scope
- `xl` 미만 화면의 "다음" 안내 배치는 기존과 동일(하단 dock 안).
- 레슨 목록(`/lesson`) 화면 변경 없음.

## Acceptance Criteria
- AC1: `xl` 이상 화면에서 "다음: ..." 안내가 콘텐츠 우측 여백에 표시되고, 하단 dock 쪽 사본은 숨겨진다.
- AC2: `xl` 미만 화면에서는 기존과 동일하게 하단 dock 안에서만 보인다.
- AC3: 작은 노트북 해상도(1366×768)에서도 "교육 설명" 패널이 과도하게 크지 않다.
- AC4: 씬 콘텐츠가 dock에 가려지는 경우, 반드시 스크롤로 전부 확인할 수 있다(스크롤이 아예 없어서 영구적으로 가려지는 경우가 없어야 한다).
- AC5: "교육 설명 숨기기/보기" 토글이 항상 정상 동작한다(로딩 완료 직후에도).

## Edge Cases
- 로딩 상태에서 실제 콘텐츠로 전환되는 시점 — dock/shell ref가 null → 실제 엘리먼트로 바뀌는 타이밍에 `ResizeObserver`가 반드시 붙어야 한다.
- `transitionToNext`가 없는 씬: 사이드 레일도, 하단 배너도 렌더링되지 않는다.

## Assumptions
- `xl`(1280px) 이상이면 사용자가 언급한 "작은 노트북 모니터"도 포함해 사이드 레일이 들어갈 여백이 충분하다.

## Clarifications
- Q: "다음" 안내를 어디까지 옮길지?
- A: xl 이상에서만 사이드로, 그 아래는 기존 유지(사용자 확인).
- Q: 교육 설명 숨기기가 안 된다는 리포트는 실제 버그였는가?
- A: 토글 자체는 문제 없었으나, 조사 과정에서 훨씬 심각한 별도 버그(ResizeObserver 미작동으로 인한 영구 콘텐츠 가림)를 발견해 함께 수정.

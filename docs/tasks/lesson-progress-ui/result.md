# Result

## 배경

사용자가 레퍼런스 사이트(`https://ai-work-education.leedh84.chatgpt.site/`, 동일 목적으로 고정 콘텐츠로 만든 사내 AI 교육 사이트)와 1차 Lesson 기능 구현을 비교한 결과, "진행 UI"(코스 개요, 진행률, 전체 학습 흐름 탐색) 영역의 완성도 격차가 가장 크다고 판단했다. 이 문서는 그 격차를 좁히는 작업의 결과를 기록한다. 설계 문서: `docs/superpowers/specs/2026-07-30-lesson-progress-ui-design.md`. 구현 계획: `docs/superpowers/plans/2026-07-30-lesson-progress-ui.md`.

## 전달 범위

- `packages/wiki-core`에 `buildCourseOutline`/`getGlobalScenePosition` 순수 함수 추가 — 코스 전체 레슨×장면 트리, 레슨별 예상 소요시간(장면 수 × 1.5분), 특정 장면의 코스 전체 내 1-based 위치를 계산.
- `/lesson` 인덱스를 코스 로드맵 그리드로 개편 — 통계 요약 라인("N개 레슨 · M개 장면 · 약 T분") + 2열 카드 그리드(순번/제목/요약/예상시간/완료 배지).
- `/lesson/:slug` 리더 헤더에 이중 진행률("이 레슨"/"전체") 추가.
- "학습 흐름" 드로어(`LessonOutlineDrawer`) 신규 구현 — 이 코드베이스 최초의 접근성을 갖춘 모달/드로어 컴포넌트(포커스 트랩, ESC/배경 클릭 닫기, body 스크롤 잠금, 포커스 복귀를 라이브러리 없이 직접 구현). 전체 레슨×장면 트리를 보여주고, 클릭 시 같은 레슨 내에서는 즉시 전환, 다른 레슨이면 라우팅 이동.

## 주요 결정

- 예상 소요시간은 콘텐츠 관리 에이전트의 별도 입력 없이 장면 수 기반으로 자동 계산(장면당 1.5분).
- 시각 스타일은 레퍼런스의 색상/브랜드(네이비·틸)를 따르지 않고 기존 SFOOD 위키 디자인 토큰을 그대로 사용 — 레이아웃 구조(로드맵 그리드, 이중 진행률, 트리형 드로어)만 참고.
- `/lesson` 인덱스는 "코스 로드맵"(전체 개요), 리더의 드로어는 "전체 장면 트리 빠른 이동"으로 역할을 분리.
- Scene 시각 컴포넌트(카드형 비교, 노드 다이어그램), 진행자 도우미 4단 구조, 모션/전환은 이번 스코프에서 명시적으로 제외 — 후속 별도 스코프.

## 검증

`docs/tasks/lesson-progress-ui/test-result.md` 참고. `pnpm -r typecheck`/`pnpm -r test`(전체 388개 테스트: wiki-core 201, web 101, mcp-server 42, edge-sidebar 23, serverless 21)/`pnpm --filter @sfood/web build` 전부 통과. Playwright로 라이트·다크 + 데스크톱(1280)·모바일(390)에서 코스 로드맵, 이중 진행률, 드로어 열기/장면 이동(같은 레슨·다른 레슨 모두)/ESC 닫힘/배경 클릭 닫힘/포커스 복귀를 직접 확인. 레퍼런스 사이트와 나란히 비교해 구조적 유사도(로드맵 카드 배치, 진행률 이중 표기, 트리형 전체 탐색)를 확인했다.

Codex 크리티컬 리뷰에서 2건 발견: (1) 포커스 트랩이 포커스가 패널 밖으로 벗어난 상태를 감지하지 못하는 접근성 결함 — 수정 완료, 회귀 테스트 추가. (2) `next` 체인이 끊긴 레슨이 슬러그 직접 조회로는 렌더링되지만 코스 개요/드로어에서는 누락될 수 있는 엣지 케이스 — 콘텐츠 저작 문제이며 코드는 이미 안전하게(크래시 없이) 처리하므로 알려진 한계로 남김.

## 남은 갭 / 후속 과제

- **끊긴 `next` 체인 레슨의 개요 누락**(Codex 발견, 미수정): `getLessonDocumentFrom`(슬러그 직접 조회)과 `listLessonDocumentsFrom`(체인 순회)의 판단 기준이 달라, `next` 체인이 끊기거나 다중 루트가 생기면 특정 레슨이 리더에서는 정상 표시되지만 코스 개요·이중 진행률·학습 흐름 드로어에서는 조용히 빠질 수 있다. 크래시나 잘못된 숫자 표시는 없지만(안전하게 숨김 처리), 콘텐츠 작성 가이드에 "레슨은 반드시 단일 `next` 체인으로 연결할 것"을 명시하거나, 후속 Course Manifest 도입 시 이 문제를 구조적으로 해결해야 한다.
- Scene 시각 컴포넌트, 진행자 도우미 4단 구조, 모션/전환은 설계 문서에 명시된 대로 후속 세션 범위.
- 스크린리더 실측 검증(NVDA/VoiceOver)은 미수행 — 코드/자동화 테스트/수동 키보드 검증까지만 완료.

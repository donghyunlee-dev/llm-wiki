# site-header-ci-logo Spec

## Problem Statement
`docs/prd/SFOOD_CI_Normal_Small.png`에 공식 회사 CI 로고가 있는데, 위키 사이트 좌상단은 임의로 만든 빨간 사각형 "S" 마크 + "SFOOD AI WIKI" 텍스트를 쓰고 있었다. 실제 CI 로고로 교체한다.

## Scope
- `SiteHeader`의 브랜드 마크(`.site-brand-mark`, 빨간 "S" 박스)를 실제 CI 로고 이미지로 교체.
- 로고 원본(1000×212)을 헤더 높이에 맞게 리사이즈해서 배포(레티나 대비 2x 해상도로 내보냄).
- 로고에는 이미 "S FOOD"가 표현되므로, 옆 텍스트는 "AI WIKI"만 남김(중복 제거).
- 다크 테마에서 로고의 "FOOD" 회색 글자가 흐리게 보이는 문제 — 다크 전용 버전(글자만 밝은 회색으로 재도색, 빨간 "S"는 원본 유지)을 만들어 테마에 맞춰 교체.

## Out Of Scope
- 파비콘 변경 없음(기존 `favicon.svg` 유지).
- CI 로고 자체의 재제작/벡터화 없음(제공된 PNG를 리사이즈/재도색만).

## Acceptance Criteria
- AC1: 좌상단에 실제 SFOOD CI 로고가 표시되고, 헤더 높이(기존 마크와 동일한 28px)에 자연스럽게 맞는다.
- AC2: 라이트/다크 테마 모두에서 로고 글자가 충분한 대비로 읽힌다.
- AC3: 모바일 폭에서도 레이아웃이 깨지지 않는다.
- AC4: 기존 테스트가 새 마크업(로고 이미지 + "AI WIKI" 텍스트)을 검증하도록 갱신된다.

## Assumptions
- 헤더의 기존 마크 높이(28px, `h-7`)를 유지하는 것이 사이트 다른 요소와의 비례에 가장 잘 맞는다.

# Result: Playbook 검색 로깅

검색 Playbook 기록 방식을 월별 페이지에서 일별 페이지로 변경했다.

- 페이지 제목은 KST 기준 `Playbook - YYYY-MM-DD` 형식으로 생성한다.
- 새 일별 페이지는 하나의 로그 테이블을 만든다.
- 같은 일별 페이지에 추가 기록할 때는 기존 `<tbody>` 안에 검색 1건을 한 행으로 추가한다.
- 항목마다 별도 테이블을 만들던 구조를 제거해 한 페이지에서 로그처럼 읽히도록 정리했다.

검증은 wiki-core 테스트, wiki-core 타입체크, 전체 타입체크, 전체 테스트로 완료했다.

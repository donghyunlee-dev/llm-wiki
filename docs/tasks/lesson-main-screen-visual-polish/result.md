# lesson-main-screen-visual-polish Result

## Delivered Scope
UI/UX 진단 리포트의 "오픈 전 필수" 3건 중 사용자 확인을 거쳐 2건을 진행했다(신뢰 신호는 실제 데이터가 없어 보류).

1. 히어로에 오리지널 SVG 일러스트(레슨 카드 + AI 노드 네트워크) 추가, 2열 레이아웃으로 재구성.
2. 목록 화면을 챕터별 5색 팔레트로 구분 — 헤더 텍스트, 레슨 행 순번, 좌측 강조선에 일관 적용.

## Changed Files
- `apps/web/src/ui/pages/LessonHeroIllustration.tsx` (신규)
- `apps/web/src/ui/pages/LessonIndexPage.tsx` — 히어로 2열 레이아웃, 챕터 색 인덱스 계산/적용
- `apps/web/src/styles.css` — `--chapter-color-1~5`(라이트/다크) 토큰, 히어로/일러스트/챕터 색 CSS

## Key Decisions
- **참고 레퍼런스 일러스트 재사용 안 함, 이미지 생성 도구도 없음 → 직접 그린 SVG로 대체**(사용자 확인). `rect`/`circle`/`line` 기본 도형만 사용해 복잡한 path 데이터를 손으로 작성하지 않았고, 색은 전부 CSS 변수 참조라 테마 전환 시 자동으로 맞춰진다.
- **신뢰 신호는 이번 라운드에서 보류**(사용자 확인) — 수강생 수·이수율 등 실제 데이터가 없는 상태에서 지어내지 않기로 함. 향후 실제 데이터가 생기면 재검토.
- **챕터 색은 브랜드 accent(레드)와 겹치지 않는 별도 5색**으로 정의 — 6번째 챕터부터는 팔레트를 순환 재사용하되, 리스트 상 충분히 떨어져 있어 혼동 우려는 낮다고 판단.

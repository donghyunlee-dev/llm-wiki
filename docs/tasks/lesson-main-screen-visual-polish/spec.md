# lesson-main-screen-visual-polish Spec

## Problem Statement
UI/UX 진단 리포트(아티팩트) 결과, `/lesson` 화면이 실제 교육 서비스(인프런/Duolingo/SFOOD 참고 레퍼런스) 대비 시각 자산·색상 다양성이 없어 "관리자 목록"처럼 보인다는 결론. 오픈 전 필수 3건 중 사용자 확인을 거쳐 아래 2건을 진행한다.

## Scope
1. **히어로 일러스트**: 참고 레퍼런스의 일러스트는 제3자 사이트 산출물이라 재사용 불가, 이미지 생성 도구도 없음 → 직접 그린 SVG(기하학적 구성)로 히어로에 시각적 후크 추가.
2. **목록 색 다양화**: 챕터별로 색을 구분해 "동일한 텍스트 행 반복" 문제를 완화 — 챕터 헤더 + 해당 챕터에 속한 레슨 행의 순번 배지 + 좌측 강조선에 챕터별 고유 색상 적용.

## Out Of Scope (이번 라운드 보류)
- **신뢰 신호**(수강생 수, 이수율 등) — 실제 데이터가 없어 지어낼 수 없음. 사용자 확인 후 보류.
- 완료/진행 표시 재도입, 모션 추가, 아이콘 세트 — "차기 스프린트" 항목으로 리포트에 이미 문서화, 이번 라운드에서는 진행하지 않음.
- 레슨 리더 화면 자체의 추가 시각 개편 — 이번 라운드는 `/lesson` 목록 화면에 한정.

## User Or Operator Scenarios
- 사용자가 `/lesson`에 진입하면 텍스트만 있던 히어로에 브랜드 컬러 기반 오리지널 일러스트가 함께 보인다.
- 사용자가 23개 레슨 목록을 훑을 때, 챕터마다 다른 색이 헤더·순번·좌측선에 일관되게 적용되어 있어 챕터 구분이 시각적으로도 즉시 인지된다.

## Acceptance Criteria
- AC1: 히어로에 이미지 파일이 아닌 인라인 SVG(라이선스 이슈 없음)가 표시되고, 라이트/다크 테마 모두에서 톤이 맞는다.
- AC2: 6개 챕터가 서로 다른 색(팔레트 순환)으로 구분되고, 같은 챕터에 속한 레슨 행들은 동일한 색 계열로 묶여 보인다.
- AC3: 기존 회귀(테스트/타입체크) 없음.

## Assumptions
- 챕터 색상 팔레트는 기존 `--accent`(브랜드 레드)와 겹치지 않는 별도 4~5색으로 신규 정의한다.
- SVG 일러스트는 외부 리소스/이미지 파일 없이 코드로만 구성한다(라이선스 문제 원천 차단).

## Clarifications
- Q: 히어로 그래픽을 어떻게 만들지?
- A: 직접 그린 SVG 일러스트(AskUserQuestion으로 확인).
- Q: 신뢰 신호로 무엇을 노출할지?
- A: 지금은 생략하고 보류(AskUserQuestion으로 확인) — 실제 데이터 없이 지어내지 않는다.
